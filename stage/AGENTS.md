# Stage console design instructions

Before changing the operator interface, read [BRAND.md](BRAND.md) and follow its color, typography, layout, and interaction rules. Preserve speaker notes as the primary surface and keep Settings and Scenes closed by default. The guide describes the target design; existing styles are not exceptions to it. Audience projections follow the script’s art direction separately.

Use existing local tools or containers when additional software is needed; avoid installing software on this host.
