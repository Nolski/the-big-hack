Editing the script

Every line on this page is already a text box — there is nothing to open and nothing to close, and nothing collapses while you work. Typing is written to the shared script (stage/show.json) a moment after you stop, and the version it replaces is kept in stage/script-history/. Every save carries the script revision it was loaded against; if someone else has saved since, you are asked to reload before continuing.

Tab · ⇧Tab
next / previous box
↑ ↓
move a line; at the ends of a beat, into the beat above / below
Enter
next beat (a beat's words are one paragraph)
⌥Enter
new beat below this one, same speaker
⌘⌫
delete this beat
⌘Z · ⇧⌘Z
undo / redo the last script edit, from anyone (in a box you've typed in, it undoes your typing instead)
⌥F
flag this beat to come back to
⌘Enter
mark the scene proofed and go to the next one
⌘F · /
find (and replace) across every scene
N · P
next / previous scene, when you're not in a box
Esc
step out of the text
⌘S
write everything now — it does this on its own anyway
Running time

Each line's ElevenLabs recording, scaled to the 105-minute walkthrough of the uncut script (stage/runtime-baseline.json). Lines whose recording no longer matches their words are estimated from the word count until they are regenerated.
